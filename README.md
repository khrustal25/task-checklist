# website-vibecoder

Интерактивный чек-лист и трекер задач в одном HTML-файле. Светлая и тёмная тема, прогресс выполнения, фильтры и сохранение списка в браузере.

> Проект пока только готовится к загрузке в репозиторий. Сайт ещё не опубликован.

## Что есть на сайте

- Заголовок с текущей датой
- Круговой индикатор и полоска прогресса (сколько задач выполнено)
- Поле ввода и кнопка «Добавить» для новых задач
- Фильтры: все / активные / готовые
- Кнопка «Удалить готовые»
- Список задач с отметкой выполнения и удалением
- Редактирование текста задачи по нажатию
- Уведомление «Задача удалена» с кнопкой «Вернуть»
- Переключатель светлой / тёмной темы (кнопка в правом нижнем углу)

## Технологии

- HTML
- CSS
- JavaScript
- Шрифты Google Fonts: Manrope и Plus Jakarta Sans
- Данные хранятся в `localStorage` браузера (без сервера и базы данных)

Сборка и установка пакетов не нужны.

## Как запустить локально

1. Откройте папку проекта на компьютере.
2. Дважды щёлкните по файлу `index.html` — сайт откроется в браузере.

Или через локальный сервер (если он уже установлен Python):

```bash
python -m http.server 8765
```

Затем откройте в браузере: [http://127.0.0.1:8765/](http://127.0.0.1:8765/)

## Что можно персонализировать

В файле `index.html` можно изменить:

- название в заголовке страницы и в блоке «Чек-лист задач»
- цвета светлой и тёмной темы (CSS-переменные в начале файла)
- тексты кнопок, фильтров и подсказок
- примерные задачи, которые появляются при первом открытии
- название приложения для домашнего экрана (`apple-mobile-web-app-title`)

Задачи и выбранная тема сохраняются в браузере пользователя. При очистке данных сайта они исчезнут.
